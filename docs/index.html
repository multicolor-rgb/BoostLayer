01 Manifest

Launcher ma zniknąć z drogi. Nie odwrotnie.

Bez konta, subskrypcji i pulpitu pełnego szumu. Boostlayer robi dobrze jedną rzecz: uruchamia gry dokładnie tak, jak je skonfigurujesz — i schodzi z drogi.

01

Izolacja

Osobny WINEPREFIX, środowisko i argumenty dla każdego tytułu. Zero konfliktów rejestru i wspólnego bałaganu.

02

Kontrola

Runner, skalowanie, limit klatek i komponenty Windows — wszystko jawne, w jednym miejscu. Nic nie dzieje się za Twoimi plecami.

03

Lekkość

Backend korzysta wyłącznie z biblioteki standardowej Pythona. Jedyna zależność runtime to PyQt6. Żadnego Electrona, webview ani demona.

02 Łańcuch uruchamiania

Jeden łańcuch. Zero niespodzianek.

Każda warstwa jest jawna i konfigurowalna. Widzisz dokładnie, co dzieje się między kliknięciem Graj a pierwszym kadrem.

  1. 01 GameMode Priorytet CPU / GPU
  2. 02 MangoHud Statystyki i limit FPS
  3. 03 Gamescope Skalowanie i shader cache
  4. 04 ENV Twoje zmienne i argumenty
  5. 05 Wine / Proton Runner per gra
  6. 06 WINEPREFIX Pełna izolacja
  7. 07 gra.exe Tylko to, co potrzebne

03 Funkcje

Wszystko, co robi różnicę.

Od izolacji procesów po kinowy tryb Big Picture. Każda funkcja istnieje, bo rozwiązuje realny problem — nie dlatego, że wypełnia checklistę.

05 Sklepy

Cała biblioteka. Wreszcie w jednym miejscu.

Cztery integracje, jeden wspólny model. Logowanie, dialogi postępu, katalog instalacji i pipeline uruchamiania są spójne w każdym sklepie.

01Stabilny

Steam

Importuje pliki appmanifest i okładki z lokalnego cache. Dopisuje wrapper do LaunchOptions z backupem i walidacją localconfig.vdf.

Amazon Games

06 Instalacja

Gotowe w minutę.

Pobierz AppImage albo pakiet Debian z najnowszego wydania. Bez repozytorium, kreatora instalacji i konta.

AppImagex86_64 · 69 MB ↗ .debamd64 · 54 MB ↗ 
chmod +x Boostlayer-0.1.0-x86_64.AppImage
./Boostlayer-0.1.0-x86_64.AppImage

Na X11 może być potrzebny systemowy pakiet libxcb-cursor0.

sudo apt install ./Boostlayer-0.1.0-amd64.deb

Pakiet Debian dociąga MangoHud i GameMode przez Depends.

python3 -m venv venv
. venv/bin/activate
pip install -r requirements.txt
python main.py

Python 3.10+ i PyQt6. Reszta to biblioteka standardowa.

Wymagania

  • Linux x86_64 / arm64✓
  • X11 / Wayland✓
  • Python 3.10+ (ze źródeł)✓
  • Wine — instalowany osobnowymagane
  • MangoHudopcjonalny
  • Gamescopeopcjonalny

Gry 32-bitowe wymagają 32-bitowego MangoHud. Aplikacja może zainstalować oficjalny build lib32 i biblioteki i386 GameMode.

07 FAQ

Uczciwe pytania, proste odpowiedzi.

To, czego Boostlayer nie ukrywa za marketingiem.

Pełna dokumentacja na GitHubie ↗
Czy potrzebuję zainstalowanego Wine?

Tak. Boostlayer zarządza runnerami Proton-GE i Wine-GE, ale systemowy Wine to osobny, duży pakiet i świadoma decyzja użytkownika. Aplikacja powie, czego brakuje.

Czy działa na Waylandzie i Steam Decku?

Boostlayer działa na Linuksie x86_64 i arm64, na X11 lub Waylandzie. Globalny skrót ma lokalny fallback dla Waylanda. Pad w trybie konsolowym korzysta z /dev/input/js*.

Czy zadziałają gry z anty-cheatem?

Część tak, część nie. To właściwość anty-cheata, nie launchera. Gry Amazon korzystające z FuelPump, anty-cheaty jądrowe i część starszych tytułów mogą odmówić startu pod Wine — README mówi o tym wprost.

Gdzie trafiają moje dane?

Boostlayer nie ma serwera ani telemetrii. Baza, konfiguracja i tokeny są przechowywane lokalnie w ~/.config/boostlayer. Tokeny trafiają wyłącznie do API danego sklepu, gdy łączysz się z nim bezpośrednio.

Czy muszę używać MangoHud i Gamescope?

Nie. Oba są opcjonalne. GameMode jest najbardziej zewnętrznym elementem łańcucha, MangoHud odpowiada za statystyki i limit FPS, a Gamescope za skalowanie i shader cache. Używaj tylko tego, czego potrzebujesz.

Co z Ubisoft Connect?

Planowany na kolejny etap. Ubisoft nie udostępnia publicznego API do cichych instalacji, więc integracja będzie oparta na oficjalnym kliencie w zarządzanym prefiksie Wine — bez pobierania w tle.

Czy Boostlayer jest darmowy?

Tak. Licencja MIT. Możesz czytać, modyfikować i redystrybuować kod. Nie ma płatnego planu ani konta do założenia.
